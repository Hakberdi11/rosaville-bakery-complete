# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

This directory holds the **Rosaville bakery ecosystem**: two apps that are two halves of one product, not unrelated repos.

- `rosaville-front-last/` — the public customer-facing website
- `rosaville-admin-dashboard/` — the shop owner's back-office dashboard

Detailed commands and architecture for each app live in `.claude/rules/` and load automatically. See `.claude/rules/ecosystem.md` for the two standing long-term goals (connecting the two apps' data, and removing the Base44/Manus platform dependencies) that should inform any cross-cutting or architectural work here.
